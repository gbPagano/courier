# Code of conduct

Courier's issue tracker and pull requests should stay constructive, specific, and respectful.

## Expected behavior

- Be clear and direct without being hostile.
- Keep discussions focused on the technical issue or contribution.
- Assume mistakes are fixable and ask for clarification when context is missing.
- Respect maintainers' time by providing complete reports and focused pull requests.

## Unacceptable behavior

- Harassment, insults, personal attacks, or discriminatory language.
- Reopening or duplicating issues without new information.
- Posting generated reports or generated pull requests that were not reviewed.
- Sharing secrets, private credentials, or sensitive user data in public issues.

## Enforcement

Maintainers may edit, hide, lock, or close conversations that do not follow these expectations. Repeated abuse may lead to being blocked from participating in the repository.
